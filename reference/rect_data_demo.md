# Example data for Rectangler

A small example data set used in the package documentation and examples.

## Usage

``` r
rect_data_demo
```

## Format

A data frame with 4 rows and 5 variables:

- label:

  Rectangle labels.

- value:

  Rectangle values.

- fill:

  Rectangle fill colours.

- shape_label:

  Labels used by
  [`rect_shape_label()`](https://hriisalu.github.io/rectangler/reference/rect_shape_label.md).

- annotation:

  Annotation text used by
  [`rect_annotation()`](https://hriisalu.github.io/rectangler/reference/rect_annotation.md).

## Examples

``` r
rect_data_demo
#>   label value    fill shape_label annotation
#> 1     A    10 #D9EAF7           1      First
#> 2     B    20 #F8D7DA           2     Second
#> 3     C    30 #DFF0D8           3      Third
#> 4     D    40 #FFF3CD           4     Fourth
```
